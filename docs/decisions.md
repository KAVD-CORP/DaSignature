## 2. Deliberate deviations from the spec

These two PM decisions knowingly differ from the spec text. They are recorded here so nobody
"fixes" them back, and so the owner can see exactly what changed (PM #34).

| PM # | The spec says | What was decided | Why |
|---|---|---|---|
| **#1 CSP** | Sec 5 rule 1: "Strict CSP (default-src 'self'; connect-src 'none'-style)". Sec 9: strict CSP. | `connect-src 'self' blob: data:` (not `'none'`), `script-src 'self' 'wasm-unsafe-eval'`, `style-src 'self' 'unsafe-inline'`, `worker-src 'self' blob:`. Every other directive is `'self'` or `'none'`. No remote origin appears anywhere. | Self-hosted workers, WASM (SQLite, Argon2) and the service worker must fetch same-origin and blob/data URLs; Radix UI sets inline styles. The privacy guarantee is kept by the zero-outbound-request test, which fails on any non-app origin. |
| **#16 Touch targets** (refined by #49, #52) | Sec 3.2: "44x44 pt targets" (stated without qualification). | 44x44 when the primary pointer is coarse (touch) or unknown; 32x32 minimum when the primary pointer is fine (mouse/trackpad), **at any viewport width** (PM #52; still above WCAG 2.2's 24x24). Implemented by `--size-target`: 2.75rem by default and under `@media (pointer: coarse)`, 2rem under `@media (pointer: fine)`; it does not use `any-pointer` or width queries. Hybrid devices follow their primary pointer. Utilities: `min-h-target` / `min-w-target` (`*-touch` forces 44px). | The spec's wording is about touch targets; 44px controls everywhere would bloat the mouse-driven desktop layout (Sec 8.3). |
